## 🚀 Quick Setup & Usage

### 1. Add the Tap
Tap this repository once to make all formulas available:
```bash
brew tap rakshithgoud453/tap
```

### 2. Install Tools

#### Install TermCall
Peer-to-peer encrypted voice link in your terminal. Zero accounts, zero cloud relay, pure UDP hole-punching:
```bash
brew install termcall
```

#### Install MyVault
Zero-telemetry local-first secret and environment variable manager:
```bash
brew install myvault
```

### 3. Update Installed Formulas
Keep your CLI tools up to date with the latest releases:
```bash
brew update
brew upgrade termcall myvault
```
